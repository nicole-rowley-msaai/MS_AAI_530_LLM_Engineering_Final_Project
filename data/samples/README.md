# Sample inputs

A fictional resume and job posting for trying the app and for demos.
The person, school, and companies are invented, so the files are safe to
send to the APIs and to show on screen.

| File | Contents |
|---|---|
| `sample_resume.txt` | Resume for a recent business graduate |
| `sample_job_posting.txt` | Junior Data Analyst posting |

To use them, paste each file's text into the matching box in the app's
sidebar and click "Analyze application".

The pair is a partial match on purpose. The posting asks for SQL, Tableau,
stakeholder presentations, and project leadership, and the resume has
near-misses for each ("helped build", "member of a four-person team",
"created charts for a class presentation"). This makes it a useful case
for checking whether the assistant inflates a bullet and whether the judge
catches it.
